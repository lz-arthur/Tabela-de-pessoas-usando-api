# Tabela-de-pessoas-usando-api

## Sobre o projeto
O projeto é uma tabela com dados de pessoas fictícias criada a partir de uma api, a randomuser.me.
O usuário poderá escolher um país em um select, logo depois será mostrada uma tabela de informações das pessoas do país escolhido.
Além disso, Há um sitema de ordenar com botões por idade e nome e de filtragem em tempo real que só filtra os nomes cuja composição tem o que é inserido no input.

## Funcionalidades
* Criação de tabelas com informações geradas de uma api por um select que indica a nacionalidade da pessoa.
* Ordenar por idade ou nome.
* Filtragem em tempo real por nome.
